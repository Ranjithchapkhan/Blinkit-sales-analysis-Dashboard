# 🟡 Blinkit Sales Analysis Dashboard | Power BI

## 📌 Project Overview
This project presents an interactive **Sales Analysis Dashboard** for **Blinkit** — India’s last-minute grocery delivery app — built using **Microsoft Power BI**. The dashboard provides a comprehensive view of sales performance, outlet distribution, item categories, and customer ratings to support data-driven business decisions.

---

## 🎯 Objective
To analyze Blinkit’s sales data and derive actionable insights across:
- Sales performance by outlet type, size, and location
- Product category contribution to revenue
- Impact of item attributes (e.g., fat content) on sales
- Customer satisfaction trends via average ratings

---

## 📊 Key KPIs Tracked
| KPI | Description |
|-----|-------------|
| Total Sales | Overall revenue generated |
| Average Sales | Mean revenue per outlet/item |
| Number of Items | Total distinct items sold |
| Average Rating | Customer satisfaction score |

---

## 🔍 Dashboard Features
- **Outlet Performance Analysis** — Comparison across Tier 1, Tier 2, and Tier 3 cities
- **Item Type Breakdown** — Category-wise sales contribution
- **Fat Content Analysis** — Low Fat vs Regular item sales patterns
- **Outlet Size & Type Filters** — Dynamic slicers for granular exploration
- **Trend Analysis** — Year-wise outlet establishment and revenue growth

---

## 🛠️ Tech Stack
- **Tool:** Microsoft Power BI Desktop
- **Data Processing:** Power Query (ETL)
- **Calculations:** DAX (Data Analysis Expressions)
- **Visualization:** Bar charts, Donut charts, Line charts, KPI Cards, Matrix

---

## 💡 Key Insights
- Tier 3 outlets generate a surprisingly high share of total revenue despite smaller market size.
- Medium-sized outlets outperform large outlets in average sales per item.
- Low-fat items show growing demand, reflecting consumer health awareness.
- Supermarket Type 1 is the top-performing outlet type by total sales volume.
